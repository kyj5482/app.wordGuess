## 2. 공통 불만 사항

### Heads Up! (ComplaintsBoard 평점 2.1/5)
- **결제/구매 문제**: 번들 과다 청구, 광고된 덱의 추가 결제 요구, 구매 복원 실패로 덱 소실, 커스텀 덱 추가마다 $0.99.
- **덱 관리 부실**: 받은 덱이 라이브러리에서 사라짐. 검색·즐겨찾기·설명 없이 무작위 긴 목록 하나.
- **타이머 60초 고정**: 조절 불가 — 90초로 바꾸려고 탈옥 트윅을 찾는 사용자까지 존재.
- **기술 문제**: "Time's Up" 화면 멈춤, 카드 반복 출제, 배터리 급감·발열, 끌 수 없는 카메라 녹화.
- **유료 앱인데 광고**: 라운드 전 30초 광고 + 유료 덱 팝업. 점수 기록 기능 없음.

### 무료 경쟁 앱 (Guess Up 등)
- **페이월 불만이 최다**: 대부분의 덱이 유료, 주간 $6.99라는 공격적 구독가, 무료 커스텀 덱 1개 제한.

### 웹 기반 버전 (브라우저 모션 감지)
- **iOS 13+ 권한 문제**: `DeviceOrientationEvent.requestPermission()`은 HTTPS + 사용자 제스처(버튼 탭) 필수. 페이지 로드 시 자동 요청 불가. **한번 거부하면 결과가 캐시되어 재요청 불가.**
- **더블 트리거 오작동**: 원시 orientation 이벤트를 그대로 쓰면 연속 판정 발생 → 성숙한 클론(OpenCharades)은 히스테리시스+디바운스 상태 머신 + 탭 존 폴백으로 해결. 이것이 웹 구현의 표준 패턴.

### 조사 한계
- "틸트가 너무 민감해서 실수로 스킵됐다"는 직접 인용 리뷰는 확인 못 함 (리뷰 사이트 접근 차단). 다만 웹 클론들이 하나같이 디바운스/히스테리시스를 구현한 것 자체가 이 문제가 실재함을 방증.
- "단어가 그룹에 너무 어렵다"는 직접 불만도 미확인이나, 그림 아이콘 기반 "Heads Up! Charades for Kids"의 존재와 Charades!의 "쉬운 카테고리/보조 모드"가 이 니즈에 대한 시장의 우회 대응.

## 3. 차별화 기회 (조사된 앱 중 어디에도 없는 것)

1. **인게임 힌트 시스템 (시간 페널티형)** — 전 앱에서 미발견. 막힌 단어에 힌트를 열고 시간을 차감하는 메커니즘은 명확한 공백. → 본 프로젝트 FR-24와 일치.
2. **플레이어별 난이도 적응** — Heads Up!은 덱 단위 난이도만, Charades!도 "쉬운 카테고리 고르기" 수준. 개인 성과 기반 자동 조정은 전무. → FR-14.
3. **그룹 지식 캘리브레이션** — "이 그룹이 아는 단어 비율" 사전 테스트 개념은 어떤 앱에도 없음. Heads Up! 최다 불만(카드 반복, 덱-그룹 미스매치)을 직접 해결. → FR-13.
4. **연령 스펙트럼 통합 (유아→성인)** — 현재는 별도 Kids 앱이나 별매 덱으로 파편화. 한 앱에서 연령 레벨로 커버하는 제품 없음. → FR-41.
5. **타이머 커스터마이즈** — Heads Up! 60초 고정은 문서화된 불만. 조절 가능 타이머만으로도 차별점. → FR-25.
6. **덱 관리 UX** — 검색·즐겨찾기·설명 부재가 1위 앱의 반복 불만 → 낮은 비용의 차별화.
7. **웹(PWA) 구현 레퍼런스** — OpenCharades가 증명한 패턴(히스테리시스 틸트 + 탭 폴백 + 정적 호스팅)이 사실상 유일한 고품질 웹 구현. iOS 권한은 "시작 버튼 탭 시 요청 + 거부 시 탭 존 폴백"이 검증된 해법.

## 4. 핵심 시사점

시장 선두(Heads Up!)의 불만은 게임플레이가 아니라 **콘텐츠 관리·결제·경직된 설정**에 집중되어 있고, 무료 경쟁작의 불만은 **페이월**이다. 따라서 본 프로젝트의 게임플레이 혁신 3종 — **힌트+시간 페널티, 그룹 캘리브레이션, 연령 적응** — 은 전부 무주공산이며, 무료 웹 배포(GitHub Pages)는 경쟁 앱들의 페이월 불만에 대한 직접적 대안이 된다.
