# Word Guess — 요구사항 정의서

> 작성일: 2026-08-03 · 상태: 초안 (벤치마크 결과 반영 전)

## 1. 제품 개요

놀이동산 대기줄 등 친구들과 함께 기다리는 상황에서 즐기는 **이마 단어 맞추기 파티 게임**.
한 명이 폰을 이마에 대고, 화면의 단어를 친구들이 설명하면 맞추는 방식. 폰 기울임(모션)으로
**정답 / Skip / Hint**를 조작한다.

- 1차 배포: **GitHub Pages** (모바일 웹 / PWA)
- 2차 배포: 앱 스토어 (추후, Capacitor 등 래핑 예정)
- 언어: 단어는 **영어 우선**, UI는 한국어/영어

## 2. 핵심 차별화 포인트

유사 앱(Heads Up! 등)이 많으므로 아래가 차별화 축이다.

| # | 차별화 요소 | 설명 |
|---|---|---|
| 1 | **그룹 캘리브레이션** | 게임 시작 전 참가자들을 돌아가며 간단히 테스트해, 그룹이 단어의 **약 70%를 아는** 공통 카테고리/난이도를 찾아 제안 |
| 2 | **개인 맞춤 난이도** | 같은 카테고리라도 차례(설명자/맞추는 사람)에 따라 개인별 레벨로 단어 조정 |
| 3 | **2단계 Hint 시스템** | 1회차: 그림(이미지) 힌트 → 2회차: 텍스트 힌트. 사용 시 시간 감점 |
| 4 | **전 연령 커버리지** | 유아~성인까지 커버하는 단어 레벨 체계 (레벨별 태깅된 단어 DB) |
| 5 | **오작동 없는 모션 UX** | 실수로 두 번 Skip되는 등의 오작동 방지가 최우선 품질 기준 |

## 3. 기능 요구사항

### 3.1 게임 세팅 (FR-1x)

- **FR-11** 참가자 등록: 이름(닉네임)만 간단히 입력. 로그인 불필요 (로컬 저장).
- **FR-12** 카테고리 직접 선택: 카테고리 목록에서 바로 선택해 시작 가능.
- **FR-13** 그룹 캘리브레이션 모드:
  - 참가자를 돌아가며 후보 단어 몇 개씩 보여주고 "안다 / 모른다" 응답 수집 (빠른 스와이프/탭).
  - 응답 결과로 그룹 인지율을 추정, **인지율 ~70%인 카테고리 × 난이도 조합**을 상위 N개 제안.
  - 테스트는 짧아야 함 (인당 30초 이내 목표) — 대기줄 상황이므로.
- **FR-14** 참가자별 레벨 프로필 저장: 캘리브레이션/플레이 결과를 로컬에 누적해 다음 게임에서 재활용.

### 3.2 게임 플레이 (FR-2x)

- **FR-21** 라운드: 설명자(폰을 든 사람) 1명 + 나머지가 힌트 제공… 이 아니라 **폰을 이마에 든 사람이 맞추는 사람**, 나머지가 설명. 제한 시간 내 최대한 많이 맞춤.
- **FR-22** 모션 조작 (이마에 든 상태, 가로 모드):
  - **정답**: 폰을 아래로 기울임 (tilt down)
  - **Skip**: 폰을 위로 기울임 (tilt up)
  - **Hint**: 별도 제스처 또는 화면 탭 (설명자가 아닌 **설명하는 친구**가 폰 화면을 보는 게 아니므로, Hint는 설명자 측 보조 화면/제스처 설계 필요 — 설계서에서 확정)
- **FR-23** 모션 오작동 방지: 임계값 + 히스테리시스 + 쿨다운 + "중립 복귀 후 재인식" 필수. 연속 더블 트리거 0건이 목표.
- **FR-24** Hint 규칙:
  - 1회차 Hint: 그림 기반 (이모지/아이콘/일러스트) — 설명하는 사람이 보고 설명에 활용.
  - 2회차 Hint: 텍스트 힌트까지 표시.
  - Hint 사용 시 **시간 감점** (예: 남은 시간 −5초, 수치는 설계에서 확정).
- **FR-25** 타이머: 라운드당 제한 시간 (기본 60초, 설정 가능). 종료 임박 사운드/진동 피드백.
- **FR-26** 피드백: 정답/Skip/Hint 각각 구분되는 사운드 + 화면 플래시 → 이마에 대고 있어도 동작 인식 여부를 알 수 있게.
- **FR-27** 폴백 조작: 모션 권한 거부/미지원 시 탭 존(화면 상/하 터치)으로 동일 조작 가능.

### 3.3 결과 및 진행 (FR-3x)

- **FR-31** 라운드 결과: 맞춘 단어 / Skip한 단어 / Hint 사용 내역 리뷰 화면.
- **FR-32** 점수: 정답 +1, Skip 0, Hint는 시간 감점으로만 반영 (단순하게 유지).
- **FR-33** 다음 차례 자동 안내: 참가자 순환.

### 3.4 콘텐츠 (FR-4x)

- **FR-41** 단어 DB: 카테고리 × 난이도 레벨(유아/어린이/청소년/성인/고급) 태깅. 영어 단어 우선.
- **FR-42** 각 단어에 그림 힌트(이모지 또는 이미지 참조)와 텍스트 힌트 1개 이상 포함.
- **FR-43** 카테고리 다양성: 동물, 음식, 직업, 영화, 스포츠, 일상 사물 등 — 벤치마크 후 목록 확정.

## 4. 비기능 요구사항

- **NFR-1** GitHub Pages 정적 호스팅으로 동작 (서버 불필요, 오프라인 캐시 PWA).
- **NFR-2** 모바일 브라우저 우선: iOS Safari, Android Chrome. iOS 모션 권한 플로우 필수 대응.
- **NFR-3** 게임 중 화면 꺼짐 방지 (Wake Lock 또는 폴백).
- **NFR-4** 데이터는 전부 로컬(localStorage/IndexedDB). 개인정보 수집 없음.
- **NFR-5** 추후 앱 패키징(Capacitor 등)을 고려한 구조 — 웹 API 의존부를 어댑터로 격리.

## 5. 미확정 항목 (설계서에서 결정)

- Hint 제스처의 구체 방식 (설명자가 화면을 못 보는 상태에서 누가/어떻게 발동하는가)
- Hint 시간 감점 수치, 라운드 시간 기본값
- 캘리브레이션 알고리즘 상세 (단어 샘플 수, 70% 추정 방법)
- 기술 스택 (프레임워크, 빌드 도구) — 모션 API 조사 결과 반영
- 카테고리/단어 초기 세트 규모
